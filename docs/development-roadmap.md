# 개발 로드맵

아래 일정은 초기 추정이며 팀 규모, 범위, VAN/프린터 장비 확보에 따라 변동됩니다.

| 단계 | 주요 범위 | 예상 기간 |
|---|---|---:|
| 1 | 모노레포, 인증, tenant/store, 직원 권한 | 1~2주 |
| 2 | 메뉴/옵션/테이블/주문/주방 티켓 | 3~4주 |
| 3 | SQLite 로컬 저장, outbox/inbox, 동기화 | 3~4주 |
| 4 | 결제 연동, 영수증/주방 프린터 | 2~4주 |
| 5 | 관리자, 주방 디스플레이, 매출/마감 | 2~3주 |
| 6 | 재고/레시피/원가/발주 | 2~3주 |
| 7 | QR/모바일 주문, 다중 매장/구독 | 2~3주 |
| 8 | 보안 점검, 복구, 현장 파일럿, 상용화 | 2~3주 |

총 17~26주 수준의 초기 추정입니다.

## MVP 완료 기준
- 직원 로그인과 매장 권한 검증
- 카테고리/메뉴/옵션 관리
- 매장 식사/포장/전화 주문 등록 및 상태 변경
- 주문 항목 가격 스냅샷
- 로컬 DB 기반 오프라인 주문 입력
- 온라인 복구 후 중복 없이 동기화
- 현금 결제 및 영수증 출력
- 관리자 주문 조회와 기본 매출 집계
- 로그/백업/복구 시나리오 테스트

## 품질 게이트
단위/통합/권한 테스트 외에 오프라인-온라인 전환, 앱 강제 종료, 프린터 연결 해제, 중복 요청, 서버 타임아웃, 부분 결제/환불을 검증합니다.
